Privacy

Stow sends nothing about you anywhere. What it reads stays on your Mac.

The app

Stow reads your agents' memory, instructions, skills, servers and transcripts where each agent keeps them, and keeps an index of them on your Mac. There is no account, no analytics and no telemetry. Nothing about you or your files is sent to us, because there is nowhere for it to go.

Secrets in config files are never shown, indexed or sent.

When it goes online

Twice, and only for what you can see it doing. To show an MCP server's own icon, Stow asks that server's site for it. To add skills from a repository you name, it fetches that repository. Neither request carries anything from your files.

Models

A model reads your library only if you switch one on. It is then asked through the Claude or Codex command you are already signed in to, on your own plan, under that tool's own terms. Stow never sees a login token, and each source can be kept out of what is sent.

This site

The site has no analytics and sets no cookies. Its host keeps ordinary server logs, as any web host does.

Questions

The app is open source, so every claim here can be checked in the code. To ask something, open an issue there.
